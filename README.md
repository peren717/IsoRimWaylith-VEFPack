# IsoRim Waylith - VE Framework Pack

[Vanilla Expanded Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=2023507013) pipe networks across the floors of [IsoRimZ](https://github.com/peren717/IsoRim-ProjectZ), for [IsoRim Waylith](https://github.com/peren717/IsoRim-1.7) (RimWorld 1.7).

- A pipe connects to a pipe of the same network directly above or below it, like power conduits.
- Works for every VEF pipe network (chemfuel, oxygen, astrofuel, nutrient paste and others).
- In the 3D view a vertical pipe piece links the floors, also in the pipe overlay.

Requires IsoRim Waylith, Vanilla Expanded Framework and IsoRimZ with Api 3 (without IsoRimZ the pack does nothing). Load after all three.

Vanilla Expanded Framework is made by the Vanilla Expanded team (Oskar Potocki and others). This pack contains no files of the original mod.
